## 🌟 Overview

At **Pure Blush**, we believe beauty is an empowering form of self-expression. The website provides visitors with an intuitive, mobile-first experience to discover salon offerings, browse customer reviews, view hairstyle transformations in the photo gallery, and easily book appointments.

---

## ✨ Key Features

- **Responsive Mobile-First Design**: Smooth, adaptive layouts across smartphones, tablets, laptops, and desktop screens.
- **Interactive Appointment Booking**: Easy-to-use booking form with calendar date/time selectors, paired with a clear timetable of opening hours.
- **Comprehensive Service Catalog**: Detailed haircut and styling menu with categorized pricing, descriptions, and direct booking links.
- **Team & Stylist Profiles**: Meet the creative stylists, salon leadership, and brand specialists who bring hair dreams to life.
- **Dynamic Photo Gallery**: Interactive slideshow featuring real salon work, cuts, colors, and transformations.
- **Contact Hub & Map Integration**: Embedded Google Map for straightforward navigation to our downtown location, along with dedicated phone lines and email addresses.
- **Client Testimonials & Feedback Form**: Authentic customer reviews highlighting client satisfaction and quality of care.

## 🚀 Getting Started

No build step or dependencies required. This is a lightweight, zero-dependency static site.

### Option 1: Direct Browser Launch
1. Clone or download this repository:
   ```bash
   git clone https://github.com/your-username/Pure-Blush.git
   ```
2. Navigate into the folder:
   ```bash
   cd Pure-Blush
   ```
3. Open `index.html` in your favorite web browser (Chrome, Edge, Firefox, Safari).

### Option 2: Local HTTP Server (VS Code Live Server)
- If using Visual Studio Code, right-click `index.html` and click **"Open with Live Server"**.
- Alternatively, run a simple local server using Node.js:
  ```bash
  npx serve .
  ```
